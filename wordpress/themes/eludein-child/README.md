# Thème enfant Élude In Art

Couche visuelle pour https://eludein.art (OceanWP).

**Ne pas** y placer de copies de `wp-admin`, `wp-includes`, ou des plugins WooCommerce.

Pas d’`index.php` « Silence is golden » : OceanWP n’a pas de `category.php` / `archive.php`, donc un stub dans le child **vide** `/category/blog/` et les autres archives.

Activation : Appearance → Themes → Élude In Art Child, ou zip via `python scripts/wp_theme_pack.py`.
