# Livrables Éric — Hermes

Dossier **visible par défaut** dans la WebUI (`hermeswebui.eludein.art`).

## Règle Hermes

Tout fichier **destiné à Éric** (script, audio, PDF, export…) va ici :

```
/opt/data/livrables/
```

Sous-dossier par projet si utile :

```
/opt/data/livrables/2026-07-12-hypnose/
```

**Ne pas** déposer les livrables à la racine `/opt/data/` (réservée au technique : config, cache, DB).

## Sources de référence

Documents d'entrée, briefs, assets :

```
/opt/data/sources/
```

## Accès WebUI

- Onglet **Espaces** → **Livrables** (`/opt/data/livrables`)
- Panneau **Espace de travail** → onglet **Fichiers**

Télécharger : clic droit → **Télécharger**.
